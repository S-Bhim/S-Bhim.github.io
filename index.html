TIME SERIES / CONCEPTUAL VIEW
PROJECT 03Python, Statsmodels, Scikit-learn

Global Temperature Time Series Analysis

Comparing forecasting methods and quantifying uncertainty in global temperature-anomaly records.

ARIMA / SARIMARidge regressionSTLRolling validation
Explore the approach
  • Compared 10 forecasting configurations spanning ARIMA, SARIMA, exponential smoothing, Ridge regression, and gradient boosting using rolling-origin validation and a separate 60-month holdout.
  • Applied ADF/KPSS stationarity tests, robust STL decomposition, HAC-adjusted trend inference, and block bootstrap comparisons.
  • Ridge regression achieved 0.098°C holdout MAE on the GCAG series, a 17.2% reduction against the seasonal-naive baseline.
